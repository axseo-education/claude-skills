# 안티패턴 가드 + AI Slop 방지

카피 품질을 떨어뜨리는 4대 안티패턴 + AI 특유 냄새 10종 감지/교정.

## 4대 카피 안티패턴

| 유형 | 감지 패턴 | 심각도 | 처리 |
|------|----------|--------|------|
| 광고톤 | "만나보세요/경험해보세요/확인하세요/해보세요" | CRITICAL | 자동 교체 (UGC체로 변환) |
| 특색없음 | 브랜드명 교체해도 성립하는 카피 | HIGH | 재생성 (브랜드 고유 USP 삽입) |
| 자극부족 | 후킹 점수 10점 이하 | HIGH | 재생성 (감정·상황 구체화) |
| 가독성부족 | 31자 초과, 전문용어 비중 과다 | MEDIUM | 축약 (핵심 1문장으로) |

## AI Slop 카피 10종

| # | 패턴 | 감지 예시 | 교체 방향 |
|---|------|----------|----------|
| 1 | 과도한 수식어 | "놀라운", "탁월한", "특별한" | 구체 수치로 교체 ("4주 만에 -2.3cm") |
| 2 | 기계적 전환어 | "또한", "더불어", "나아가" | 삭제 (없어도 읽힌다) |
| 3 | 불필요한 요약 반복 | "이처럼 ~합니다", "위에서 보듯" | CTA만 남기고 삭제 |
| 4 | 이모지 장식 | 🌟💎✨ 내용과 무관한 이모지 | 전면 금지 |
| 5 | 3의 법칙 남용 | "첫째~둘째~셋째" 항상 3개 | 핵심 1-2개만 |
| 6 | 볼드+콜론 리스트 | **장점:** 피부 개선 **장점:** 보습 | 산문으로 통합 |
| 7 | 챗봇 잔여 톤 | "안녕하세요!", "궁금하신가요?" | 본론 즉시 시작 |
| 8 | 뻔한 긍정 결론 | "지금 바로 경험해보세요!" | 구체 다음 스텝 ("오늘 밤 바르고 내일 아침 확인") |
| 9 | 동의어 순환 | "피부", "스킨", "피부결" 혼재 | 같은 단어 일관 사용 |
| 10 | 인위적 숫자 반올림 | "50,000개 판매" | 유기적 숫자 ("47,200개 판매") |

## 표시광고법 리스크 패턴 (참고 / 2차 사람 검수 영역)

> ⚠️ **/copy 자동 차단 X**. 마케팅 성과 우선. 강한 표현(수치/유일/효능 단정)이 CTR·ROAS 우위.
> 표시광고법·약사법·식약처 위반 가능성은 **법무·콘텐츠 검수팀(2차 사람 단계)**에서 필터.
> 본 섹션은 카피 작성 시 **참고용 표현 사전**일 뿐, 자동 floor 아님.

### 강한 표현 (성과 우위, 2차 검수 대상 가능)

| 패턴 | 예시 | 비고 |
|------|------|------|
| 수치 단정 | "X% 감소", "X일 만에", "X배 효과" | CTR 우위 — 가능하면 출처 동반 |
| 절대 우위 | "국내 유일", "최초", "1위", "최고" | 후크 강도 최상위 — 가능하면 범위 한정 |
| 효능 직접 | "치료", "재생", "다이어트", "면역력" | 카테고리에 따라 2차 검수 대상 |
| 비교 광고 | "기존 대비 X배", "타사보다" | 가능하면 비교 대상 명시 |
| 모집단 | "고객의 X%", "세대의 X%" | 가능하면 출처 |

### 안전 표현 풀 (옵션 — 검수 우려 시 대안)

| 강한 표현 | 안전 대안 |
|-----------|----------|
| "치료/재생/회복" | "케어/관리/도움" |
| "다이어트/지방분해" | "체중관리/가뿐한 라이프" |
| "{N}% 감소 (출처 없음)" | "{N}% 감소 (자체 임상 N={표본}, {기간})" |
| "국내 유일" | "{유통} {카테고리} {YYYY-MM} 1위" |

### 카피 **예시·샘플 문서** 작성 원칙 (이건 유지)

> EXAMPLES/, mockup, template 등 **샘플 문서 한정** 룰. 실제 운영 카피와 분리.

- 실제 브랜드명+제품+가격+기술 **단정 금지** (`memory/ops/feedback/core/feedback_no_brand_fact_in_examples.md`)
- placeholder 사용 의무: `{브랜드}`, `{제품}`, `{성분}`, `{N}%`, `{유통사}`, `{기간}`
- 사고 전례: 올록담을 화장품으로 단정한 2단계 오염
- **실제 광고 카피 출력에는 적용 X** — 마케팅 성과 우선

## 검수 거절 패턴 (매체별)

copy-spec.md의 검수 거절 패턴과 연동. 카피 생성 전 해당 매체 거절 패턴을 체크리스트로 적용.

| 매체 | 1순위 거절 패턴 | 자동 감지 키워드 |
|------|--------------|----------------|
| 네이버 | 근거 없는 1위/최고 | "1위", "최고", "최강" (단독) |
| Meta | 개인 속성 암시 / 플랫폼 UI 모방 | "당신이 ~라면", SNS UI 레이아웃 |
| Google | 랜딩페이지 불일치 | (런타임 체크 필요) |
| 카카오 | 이모지 오남용 / 형광색 | 이모지 3개 이상 / FOMO 배지 |

## 자동 교정 규칙

| 트리거 | 교정 방향 | 예시 |
|--------|----------|------|
| 광고톤 감지 ("만나보세요") | UGC체 변환 | → "써봤더니", "진작 쓸 걸" |
| 추상 형용사 ("다양한", "풍부한") | 구체 수치 삽입 | → "17가지 성분", "3배 더 촉촉" |
| 31자 초과 | 핵심만 축약 | 수식어 제거 → 동사+명사 핵심구 |
| 이모지 3개 이상 | 전부 삭제 | — |
| "모든 분/누구나" | 타겟 직접 호명 | → "40대 직장 여성이라면" |
