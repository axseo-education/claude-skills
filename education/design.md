# /design — 말로 만드는 HTML 산출물

`$ARGUMENTS` 로 무엇을 만들지 받습니다.

```
/design 8월 브랜드 실적 보고 슬라이드
/design 신제품 랜딩페이지, 타깃은 30대 여성
/design 캠페인 성과 대시보드
```

교육용 판본입니다. 인터넷 검색과 로컬 파일 생성만 사용하며, 외부 서버나 자동 배포는 쓰지 않습니다.

---

## Step 1 — 3가지를 먼저 확인한다

입력에서 아래가 비어 있으면 **만들기 전에 사용자에게 묻는다.** 셋 다 채워지기 전에는 HTML 을 쓰지 않는다.

| 항목 | 묻는 말 |
|------|---------|
| 무엇을 | 슬라이드 / 랜딩 / 대시보드 / 카드뉴스 / 목업 중 무엇인가 |
| 누구에게 | 대표 보고인가, 팀 공유인가, 고객 대상인가 |
| 어떤 톤 | 브랜드 색상·폰트가 정해져 있는가. 없으면 무채색 기본으로 간다 |

수치·사실이 들어가야 하는데 자료가 없으면 **지어내지 말고 회색 placeholder 로 비워 두고 무엇이 필요한지 적는다.**

## Step 2 — 3안을 먼저 보여준다

한 번에 완성본을 내지 않는다. **레이아웃 방향 3가지**를 짧게 글로 제시하고 고르게 한다.

```
A. 숫자 중심 — 큰 수치 3개를 상단에, 설명은 아래 작게
B. 이야기 중심 — 문제 → 원인 → 대응 흐름으로 위에서 아래로
C. 비교 중심 — 지난달과 이번달을 좌우로 나란히
```

고른 다음에 만든다. 이 단계를 건너뛰면 대부분 다시 만들게 된다.

## Step 3 — 단일 HTML 로 만든다

- 파일 하나로 완결한다. 외부 CSS·JS 파일을 만들지 않는다.
- 폰트는 Pretendard 를 CDN 으로 불러온다.
- 한국어는 `word-break:keep-all` 을 반드시 넣는다. 없으면 어절 중간에서 줄이 끊긴다.
- 긴 문장은 의미 덩어리 단위로 `<br>` 을 직접 넣는다. 자동 줄바꿈에 맡기지 않는다.
- 모바일에서도 깨지지 않게 `@media(max-width:768px)` 를 넣는다.

저장 위치는 사용자의 작업 폴더다. 다 만들면 **브라우저에서 자동으로 연다.**

## Step 4 — 스스로 점검한다

만든 다음 아래를 확인하고, 걸리면 고쳐서 다시 보여준다.

| 점검 | 걸리면 |
|------|--------|
| 지어낸 수치·인용이 있는가 | 지운다. placeholder 로 되돌린다 |
| 제목 아래마다 한 줄 요약이 붙어 있는가 | 절반 이상 지운다. 제목만으로 충분한 곳이 많다 |
| 이모지를 장식으로 썼는가 | 지운다 |
| 보라색 그라디언트 배경인가 | 바꾼다. 흔한 AI 결과물 인상을 준다 |
| 항목마다 아이콘이 붙어 있는가 | 줄인다 |
| 뱃지·태그·"BEST" 같은 라벨이 있는가 | 지운다. 강조는 크기와 배치로 한다 |

## Step 5 — 내보내기

사용자가 요청하면 변환한다.

- **PDF** — 브라우저 인쇄에서 PDF 로 저장. `@media print` 규칙을 미리 넣어 둔다.
- **이미지** — 화면 캡처. 카드뉴스는 1080×1080 기준으로 만든다.
- **PPTX** — 슬라이드 1장 = 섹션 1개 구조로 만들어 두고, 필요하면 캡처해서 붙인다.

---

## 하지 않는 것

- 자동 배포하지 않는다. 링크가 필요하면 사용자가 직접 올린다.
- 실제 로고·제품 사진을 SVG 로 그리지 않는다. 없으면 회색 박스와 라벨로 둔다.
- 확인 없이 브랜드 색을 정하지 않는다. 모르면 무채색으로 간다.
