# /competitor — 경쟁사 분석 (교육용)

```
/competitor 신라면
/competitor 신라면이랑 진라면이랑 불닭볶음면 비교해줘
/competitor 농심 vs 오뚜기 vs 삼양식품. 라면 시장. SWOT + 미디어 믹스.
```

교육용 판본입니다. **인터넷 검색과 로컬 파일 생성만** 사용합니다.
외부 서버·자동 배포·사내 데이터 연동은 쓰지 않습니다.

Step 1 리서치 → Step 2 분석 → Step 3 대시보드 → Step 4 공유 패키지 순으로 이어집니다.
중간에 **한 번 멈춰서 사용자에게 확인을 받습니다.**

---

## Step 0 — 무엇을 비교할지 정한다

입력을 읽고 아래를 판별한다.

| 입력 | 처리 |
|------|------|
| 브랜드가 둘 이상 | 그대로 비교 대상으로 삼는다 |
| 브랜드가 하나 | 같은 카테고리의 경쟁 브랜드를 **웹 검색으로 찾아** 후보를 제시하고 고르게 한다 |
| 브랜드가 없음 | **묻는다.** 무엇을 분석할지 없이는 시작하지 않는다 |

**어느 쪽이 자사인지도 함께 정한다.** 입력에 안 드러나면 묻는다.
자사가 정해지면 Step 2의 액션을 자사 관점으로 쓰고, 자사가 없으면(제3자 시장 조사 등)
**중립 비교로 전환하고 액션 대신 "시장에서 읽히는 것"으로 낸다.** 첫 브랜드를 임의로 자사로 보지 않는다.

브랜드가 하나일 때는 이렇게 낸다.

```
## 경쟁사 후보

이 카테고리에서 함께 볼 만한 곳입니다.
1. {브랜드} — {같은 카테고리로 본 이유}
2. {브랜드} — {이유}
3. {브랜드} — {이유}

이대로 갈까요? 빼거나 더할 곳이 있으면 말씀해 주세요.
```

비교 축(무엇을 기준으로 볼지)이 입력에 없으면 기본값으로 간다 — 시장 위치 · 제품 · 가격 · 채널 · 온라인 반응.

## Step 1 — 리서치 (모듈 5개)

브랜드마다 아래 다섯 모듈을 채운다. **웹 검색으로 찾은 것만 적는다.**

| 모듈 | 무엇을 찾나 |
|------|------------|
| **A. 기업개요** | 무엇을 파는 회사인가, 언제부터, 어느 시장에서, 어떤 위치인가 |
| **B. 재무·실적** | 공개된 매출·성장·점유율. 공시·보도자료·기사에 나온 것만 |
| **C. 고객·타겟** | 누구에게 파는가. 리뷰·커뮤니티에서 실제로 누가 사는가 |
| **D. 마케팅 전략** | 어떤 메시지로, 어떤 캠페인으로, 어떤 가격·프로모션으로 |
| **E. 디지털 프레전스** | 공식몰·SNS 채널·검색 노출·리뷰 수 등 온라인 존재감 |

### 리서치 규칙 (이게 품질을 가릅니다)

- 모듈마다 **검색어를 바꿔가며 여러 번** 찾는다. 한 번 찾고 넘어가지 않는다.
- **같은 사실을 서로 다른 출처에서 확인한다.** 한 곳에서만 나온 숫자는 그렇다고 표시한다.
- **모르는 것은 비워둔다.** 숫자를 추정해서 채우지 않는다. `자료 없음`이라고 적는다.
- 숫자에는 **출처와 기준 시점**을 함께 적는다. 둘 중 하나라도 없으면 숫자를 쓰지 않는다.
- 자사 브랜드가 비교 대상에 있으면, 자사에만 후하게 쓰지 않는다. 같은 잣대로 적는다.

### 출력 형식

브랜드마다 이렇게 낸다.

```
## {브랜드명}

### A. 기업개요
- ...

### B. 재무·실적
- {수치} (출처: {매체·문서}, {기준 시점})
- 자료 없음: {못 찾은 항목}

### C. 고객·타겟
### D. 마케팅 전략
### E. 디지털 프레전스

### 눈에 띈 것
- {다른 브랜드와 확실히 다른 지점 2~3개}
```

## 확인 지점 — 여기서 멈춘다

Step 1이 끝나면 **반드시 멈추고** 아래를 보여준 뒤 사용자 응답을 기다린다.

```
## 리서치 완료

### 채워진 정도
| 브랜드 | A | B | C | D | E |
|--------|---|---|---|---|---|
| {브랜드} | ✅ | ⚠ 일부 | ✅ | ✅ | ✅ |

⚠ 표시는 자료를 못 찾은 칸입니다.

### 비어 있는 것
- {브랜드}: {무엇이 없는지}

이대로 분석에 들어갈까요?
더 찾아야 할 것이 있으면 말씀해 주세요. ("OK" 하면 다음으로 갑니다)
```

사용자가 보강을 요청하면 그 부분만 다시 검색하고, 다시 이 확인 지점으로 돌아온다.

## Step 2 — 분석 프레임

**데이터가 충분한 프레임을 전부 실행한다.** 사용자에게 고르라고 묻지 않는다
(입력에 "SWOT으로 해줘"처럼 지정돼 있으면 그것만 한다).

| 프레임 | 무엇을 보나 | 실행 조건 |
|--------|------------|----------|
| **SWOT** | 강점·약점·기회·위협 | 모듈 A·D가 채워졌으면 |
| **4P** | 제품·가격·유통·프로모션 | 모듈 D가 채워졌으면 |
| **포지셔닝 맵** | 두 축 위에서 서로 어디 있나 | 브랜드가 셋 이상이면 |
| **미디어 믹스** | 어느 채널에 힘을 주나 | 모듈 E가 채워졌으면 |
| **퍼널** | 인지 → 관심 → 구매 어디가 강한가 | 모듈 C·E가 채워졌으면 |

실행 못 한 프레임은 **왜 못 했는지 한 줄로 적는다.** 조용히 빼지 않는다.

### 분석 → 액션 변환 (이 단계를 빼면 보고서가 됩니다)

프레임 결과를 그대로 두지 않고 **우리가 할 일**로 바꾼다.

- 상대의 강점 → 정면으로 붙을지, 비켜갈지
- 상대의 약점 → 우리가 가져올 수 있는 지점인지
- 아무도 안 하고 있는 것 → 먼저 할 값어치가 있는지

각 액션은 **누가 무엇을 언제까지**의 형태로 적는다. "강화한다" 같은 문장은 액션이 아니다.
근거가 리서치에 없는 액션은 쓰지 않는다.

**Step 0에서 자사가 없다고 정해졌으면**(중립 비교) 액션 대신 **"시장에서 읽히는 것"**으로 낸다 —
누가 무엇을 하고 있고, 비어 있는 자리가 어디인지까지만 적고 실행 주체를 지어내지 않는다.
아래 Step 3·4의 `우리가 할 일`·`할 일`도 같은 이름으로 바꾼다.

## Step 3 — 대시보드 (단일 HTML)

분석 결과를 파일 하나로 만든다. 열면 바로 보이는 형태여야 한다.

### 구조

- **탭 네비게이션**: 아래 탭들을 위쪽에서 눌러 전환한다
- **탭 1 — 요약**: 맨 위에 **핵심 수치 카드**(브랜드별로 가장 중요한 수치 하나씩, 지표명·출처·기준 시점을
  함께 표기) → 핵심 발견 3~5개 → 브랜드별 한 줄 정리.
  **출처와 기준 시점이 있는 수치가 하나도 없으면 카드를 통째로 생략한다.** 채우려고 숫자를 만들지 않는다
- **탭 2~ — 프레임별**: Step 2에서 실행한 프레임마다 한 탭
- **마지막 탭 — 그래서 우리는**: 액션 목록 (중립 비교면 **"시장에서 읽히는 것"** 탭)

**비교 차트는 같은 정의의 지표가 비교 대상 전부에 대해 모였을 때만 넣는다.**
한 브랜드에만 있는 수치는 차트로 만들지 말고 카드나 표로 낸다
(점유율과 영업이익률처럼 분모가 다른 값을 한 축에 겹치지 않는다). 막대 길이는 반드시 값에 비례시킨다.
조건을 만족하는 지표가 없으면 차트를 생략하고 표로만 낸다.

### 기술 요구사항

- **단일 HTML 파일.** 빌드 도구 없이 더블클릭으로 열려야 한다
- 스타일은 파일 안에 넣는다. 이미지는 넣지 않거나 파일 안에 박는다
- 차트가 필요하면 CDN 스크립트 한 개까지만 쓴다. 인터넷이 없어도 표는 보여야 한다
- 표·차트는 좁은 화면에서 가로로만 스크롤되게 하고, 페이지 전체가 가로로 밀리지 않게 한다
- **출처 없는 숫자를 화면에 쓰지 않는다.** 자료가 없는 칸은 `자료 없음`으로 남긴다

`{YYYY-MM}-{자사}-vs-{경쟁사}-경쟁분석.html` 로 지금 폴더에 저장하고 경로를 알려준다.
중립 비교라 자사가 없으면 `{YYYY-MM}-{카테고리}-경쟁분석.html` 로 한다.
**파일명 맨 앞에 분석 기준 연월을 반드시 붙인다** — 안 붙이면 다음 달에 같은 브랜드를 다시 돌릴 때
지난달 파일을 덮어써서 월별 비교가 불가능해진다. 같은 이름의 파일이 이미 있으면 덮어쓰지 말고 알린다.

## Step 4 — 공유 패키지

대시보드만 주면 대부분 안 열어봅니다. 붙여넣어 쓸 수 있는 형태로 같이 냅니다.

| 산출물 | 형태 |
|--------|------|
| **대시보드** | 위에서 만든 HTML 파일 |
| **요약 슬라이드** | 핵심 발견 + 액션만 담은 별도 HTML 한 장 |
| **공유 메시지** | 메신저에 그대로 붙여넣을 텍스트. 굵게·목록만 쓰고 표는 쓰지 않는다 |

공유 메시지는 이 형태로 낸다.

```
*{자사} vs {경쟁사} 경쟁 분석*
(중립 비교면 제목을 `*{카테고리} 경쟁 구도*` 로 한다)

*이번에 확인된 것*
• {발견 1}
• {발견 2}

*할 일*
• {누가} {무엇을} {언제까지}
(중립 비교면 `*시장에서 읽히는 것*` 으로 바꾸고 실행 주체를 쓰지 않는다)

자세한 내용은 첨부한 대시보드 파일을 봐주세요.
```

## 마지막에 반드시 밝힐 것

결과를 내면서 아래를 함께 적는다. 빼면 읽는 사람이 전부 사실로 받아들인다.

- **못 채운 칸** — 어느 브랜드의 어느 모듈이 비었는지
- **한 출처에서만 나온 숫자** — 교차 확인이 안 된 것
- **기준 시점** — 언제까지의 정보로 만든 분석인지

## 하지 않는 것

- 못 찾은 수치를 그럴듯하게 채우지 않는다
- 확인 지점을 건너뛰고 끝까지 달리지 않는다
- 자사에 유리한 쪽으로 프레임을 고르지 않는다
- 로그인이 필요한 페이지나 유료 자료를 우회해서 가져오지 않는다
