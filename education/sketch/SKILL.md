# Sketch — 손그림 개념 일러스트

곡선·구조·흐름을 손그림 톤 인라인 SVG로 그린다. **글로 설명하면 길어지는 개념**만 그린다.

**하이브리드 원칙**: 텍스트(본문·캡션)는 원티드 산스로 클린하게, **일러스트만 손그림**.
전체를 손글씨로 만들지 않는다 — 가독성이 무너지고 유치해진다.

## 언제 쓰나

| 쓴다 | 안 쓴다 |
|------|---------|
| 곡선 관계 (두 지표가 반대로 움직임) | 표·비교 매트릭스 (이미 시각적) |
| 구조 중첩 (계층·포함 관계) | 단순 나열 (리스트로 충분) |
| 흐름 (A→B→C 파이프라인) | 장식 목적 |
| 넓이·크기 대비 (모수·풀) | 숫자 하나 강조 |

판단 기준: **그림이 없으면 이해가 안 되는가.** 아니면 넣지 않는다.

## 삽입 방법

1. `assets/sketch.css` 내용을 `<style>`에 붙인다 (폰트 링크 2줄 포함)
2. `assets/rough-defs.html` 내용을 `<body>` 바로 뒤에 붙인다 (필터 정의, 문서당 1회)
3. `<figure class="illo">` 안에 SVG + `<figcaption>` 작성

캡션은 **그림이 말하는 결론**을 쓴다. 그림에 있는 라벨을 반복하지 않는다.

## 클래스 계약

`deck_illos.py`(SOP 교육 덱)와 동일 계약 — 양쪽에서 SVG를 그대로 옮길 수 있다.

| 클래스 | 용도 |
|--------|------|
| `sk` | 잉크선 (본선·테두리) |
| `sk-ax` | 보조축·구분선 (옅음) |
| `sk-accent` | 강조선 (문서 accent 색) |
| `sk-warn` | 경고·실패 경로 |
| `fa` / `fg` / `fw` | 채움 — accent / 회색 / 경고 |
| `lbl` / `lblm` | 라벨 — 본문 / 보조 (Gaegu 손글씨) |
| `lbla` / `lblw` | 라벨 — accent / 경고 |

색은 문서의 `--accent`·`--text`를 상속한다. 스킬이 색을 정하지 않는다.

## ⚠️ 직선 트랩 (반드시 지킬 것)

**완전한 수직·수평선에 `filter:url(#rough)`를 걸면 선이 통째로 사라진다.**
바운딩박스 폭/높이가 0이라 필터 영역이 소멸하기 때문. 사선·곡선·도형은 멀쩡해서
축·구분선·화살표 축선만 조용히 실종되고, 코드만 봐서는 절대 발견되지 않는다.

```
✗ <path class="sk-ax" d="M76 40 L76 306"/>     축이 사라진다
✓ <path class="sk-ax" d="M76 40 L78 306"/>     끝점 1~2단위 오프셋
```

손그림 톤에는 오히려 어긋난 쪽이 자연스럽다.
(`userSpaceOnUse` 필터로도 해결되지만 SVG마다 크기가 달라 공유 필터엔 부적합.)

## 레이아웃 체크리스트

좌표를 손으로 짜므로 아래를 매번 확인한다. 대부분의 실패가 여기서 난다.

- **라벨 잘림** — `text-anchor="end"` 라벨은 viewBox 왼쪽 여백을 충분히 잡았는가
- **화살표 오지시** — 화살표가 의도한 대상을 가리키는가 (옆 텍스트를 가리키기 쉽다)
- **텍스트 겹침** — 곡선·도형 위에 라벨이 얹히지 않았는가
- **테두리 걸침** — 원·박스 상단 라벨이 viewBox 밖으로 나가지 않았는가 (`viewBox="0 -34 …"`로 여백 확보)
- **선 연결** — 사선 끝점과 다음 선 시작점의 좌표가 실제로 같은가

## 검증 (생략 금지)

**눈으로 보기 전까지 완성이 아니다.** 직선 트랩과 레이아웃 실패는 코드 리뷰로 안 잡힌다.

```bash
python3 ~/.claude/skills/sketch/scripts/shot.py <html경로> <출력프리픽스>
```

`figure.illo`를 전부 캡처하고 pageerror 수를 출력한다. 캡처한 PNG를 **Read로 직접 확인**한다.

## 일러 카탈로그

기존 일러는 `illos/catalog.md` 참조 (검증된 SVG 원본 포함). 새로 그린 일러 중
재사용 가치가 있으면 카탈로그에 1회 추가한다.

SOP 교육 덱 라이브러리는 `~/brand-okr/sop/deck_illos.py` — 같은 클래스 계약이라 상호 이식 가능.
단 그쪽 기존 일러에는 직선 트랩이 잠재해 있다 (예: funnel 목 `M205 250 L205 300`).
