# /copy 교차검증 스펙

/review-loop / /critique 실행 시 참조.

## 기본 검증 축 (전 모드 공통)

| 축 | 가중치 | 기준 |
|----|--------|------|
| 프레임워크 정합성 | 25 | 인지레벨 × 매체에 맞는 프레임워크가 선택되었는가 (`framework_selector.md` 매트릭스 기준) |
| 후킹 임팩트 | 30 | 첫 줄이 스크롤을 멈추는가. 후킹 엔진 8유형 중 적합한 것이 적용되었는가 |
| 매체 제약 준수 | 20 | 글자수 초과 없는가. 검수 거절 패턴 위반 없는가 (`_shared/lib/copy-spec.md`) |
| 자가발전 일관성 | 25 | 본질 프레임워크가 유지되면서 트렌드가 반영되었는가. 가중치 시스템 작동하는가 |

## 크리티컬 체크 (이진 floor — 1건이라도 위반 시 즉시 리젝)

- [ ] 4축 스코어링 80점 floor 준수
- [ ] 광고톤 안티패턴 0건 (`antipattern_guard.md` CRITICAL)
- [ ] AI Slop 카피 0건 (10종)
- [ ] 매체별 글자수 100% 준수
- [ ] 골드 스탠다드 대비 편차 15점 이내
- [ ] **brand fact 단정 0건 (샘플 문서 한정)** — EXAMPLES/mockup/template 등 **샘플 문서**에서 실제 브랜드명+제품+가격+기술 단정 없음. placeholder(`{브랜드}`, `{제품}`, `{N}%` 등) 사용. 실제 운영 카피엔 적용 X (`memory/ops/feedback/core/feedback_no_brand_fact_in_examples.md`)

> **표시광고법 / 약사법 / 식약처 규제는 자동 floor 아님**. 강한 표현(수치/유일/효능 단정)이 마케팅 성과 우위. 규제 위반 가능성은 **법무·콘텐츠 검수팀(2차 사람 단계)**에서 필터. /copy는 마케팅 성과에만 치중.

## ab_test 모드 전용 검증 (모드 활성 시만)

| 축 | 가중치 | 기준 |
|----|--------|------|
| 변수 통제 일관성 | 30 | 단일 변수 외 나머지 고정. 후크 변형 셋이면 베네핏·CTA가 모든 변형에서 100% 동일 |
| 단일 프레임워크 | 20 | 변형 N안 모두 동일 프레임워크 적용 (기본 모드와 반대) |
| 페르소나 매칭도 명시 | 25 | 각 변형에 대상 페르소나 + 매칭 근거 명시 |
| 변수 매핑 표기 | 25 | 반환 스키마에 `variable: hook|benefit|cta` 명시 + 변형별 변수값 차이 추적 가능 |

ab_test 4원칙 (SKILL.md §ab_test 모드 상세) 위반 시 즉시 리젝:
- [ ] 한 번에 1개 변수만 변경
- [ ] 후크/베네핏/CTA 각각 독립 변수
- [ ] 조합 매트릭스 (후크 4종 × CTA 4종 = 16조합) 추적 가능
- [ ] 상위 4조합 추천 시 선정 근거 명시 (페르소나 매칭도 / 레퍼런스 검증 패턴 / 퍼널 위치 적합성)

## 리젝 대상이 아닌 것

- 특정 프레임워크 선호 차이 (PAS vs BAB)
- 후크 유형 선택 차이 (수치형 vs 의문형)
- 톤 미세 조정
- ab_test 모드에서 단일 프레임워크 사용 (의도된 통제)
