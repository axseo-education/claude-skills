# CTA 4유형 + 매체별 CTA 규칙

## 4대 CTA 유형

| 유형 | 패턴 | 예시 |
|------|------|------|
| 긴급성 | 시간/수량 제한 | "오늘 자정까지 >>", "300개 한정 >>" |
| 호기심 | 정보 갈증 유발 | "이유가 있습니다 >>", "비밀 성분 확인" |
| 혜택 | 구체적 할인/증정 | ">> 52% 할인", "1+1 >>", "무료 배송 >>" |
| 사회적증거 | 군중 심리 | "15차 완판 >> 지금 입장", "5,580명이 선택 >>" |

### 1. 긴급성 CTA
**심리 원칙**: 희소성(Scarcity) — 수량/시간이 제한될수록 욕구 상승  
**패턴**: 마감 시간 명시 + ">>" 화살표 + 행동 동사  
**예시**:
- "오늘 자정까지 >> 특가 적용"
- "300개 한정 >> 지금 구매"
- "마감 D-2 >> 놓치면 정가로"

### 2. 호기심 CTA
**심리 원칙**: Curiosity Gap — 정보 격차를 인식할 때 클릭 충동 발생  
**패턴**: 불완전한 정보 제시 → 클릭으로 해소 유도  
**예시**:
- "이유가 있습니다 >> 확인하기"
- "비밀 성분 직접 확인 >>"
- "더 알아보기 >> (생각보다 간단해요)"

### 3. 혜택 CTA
**심리 원칙**: 손실 회피(Loss Aversion) — 혜택을 놓치는 것이 혜택을 얻는 것보다 강하게 작용  
**패턴**: 구체 수치 + 혜택 명시 + ">>" 방향  
**예시**:
- ">> 52% 할인 — 오늘만"
- "1+1 >> 지금 바로 담기"
- "무료 배송 >> 오늘만 적용"

### 4. 사회적증거 CTA
**심리 원칙**: Social Proof — 다수의 선택이 의사결정 불확실성 해소  
**패턴**: 수치/완판 이력 + >> + 입장/확인 동사  
**예시**:
- "15차 완판 >> 지금 입장"
- "5,580명이 선택 >> 나도 보기"
- "리뷰 4.9 >> 직접 확인하기"

## 매체별 CTA 규칙

| 매체 | CTA 형태 | 필수 규칙 | 금지 |
|------|---------|---------|------|
| GFA | 버튼 선택형 | 이커머스 전환은 반드시 "구매하기" (네이버 정책) | 임의 문구 작성 |
| Meta Feed/Reels | 버튼 선택형 | Shop Now / Learn More / Sign Up 중 선택 | 버튼 텍스트 직접 수정 |
| Google RSA | 본문 삽입형 | 설명문 마지막 줄에 CTA 삽입 | 헤드라인에 CTA 중복 |
| 카카오 | 버튼 선택형 | 버튼 텍스트 15자 이내 | 과도한 특수문자 |
| 뉴스레터 | 링크 텍스트형 | 본문 내 자연스러운 링크 삽입 | ">>" 남용 (광고 냄새) |
| 카드뉴스 | 마지막 슬라이드 | 슬라이드 1장 전체를 CTA로 활용 | CTA 없는 마지막 슬라이드 |

## CTA 스코어링

**">>" 화살표 효과**: CCFM 4,206개 소재 데이터 기준, ">>" 포함 시 클릭율 평균 12% 상승

**최강 조합**: 숫자 + 혜택 + ">>"
- ">> 52% 할인" (수치+혜택+화살표)
- "300개 한정 >> 지금 구매" (희소성+화살표+동사)

**뉴스레터·콘텐츠형 매체에서 ">>" 지양**: 광고 냄새 → 신뢰도 저하. 링크 텍스트나 버튼형으로 대체.

**CTA 길이 기준**:
- 퍼포먼스 광고: 10~20자 이내
- 뉴스레터 링크: 5~15자 (자연스러운 문장 내 삽입)
- 카드뉴스 마지막 슬라이드: 15~25자 (임팩트 있게)

## 소구점별 최적 CTA 유형

| 소구점 | 1순위 CTA | 2순위 CTA | 이유 |
|--------|----------|----------|------|
| 효능/결과 | 호기심 | 사회적증거 | 결과가 궁금하게 만들어 클릭 유도 |
| 가성비/절약 | 혜택 | 긴급성 | 구체 절약액이 즉각 행동 유발 |
| 사회적 증거 | 사회적증거 | 호기심 | 군중 수치 직접 활용 |
| 공포/회피 | 긴급성 | 호기심 | 지금 행동하지 않으면 손해 프레임 |
| 감성/공감 | 호기심 | 혜택 | 감성 흐름 유지하며 부드럽게 유도 |
| 희소성/긴급성 | 긴급성 | 사회적증거 | 마감+다수 선택 결합이 최강 |
