# 레이어와 판정 읽기

전 레이어를 평가하며 대표 우선순위는 L3 > L4 > L2 > L5 > L1 > L0이다.
CPA는 확정한 목표 CPA, CTR은 링크 클릭/노출이다. 문턱의 `>`와 `<`는 등호를 포함하지 않는다.

| 레이어 | 조건 | 평가 창 |
| :--- | :--- | :--- |
| L0 미도달 | 광고 세트 시작 시각과 생성 시각 중 늦은 쪽부터 72시간 초과, 생애 지출 2천 원 미만 | 생애 |
| L1 CTR | 숙성 지출 > CPA의 0.125배, CTR < 14일 일별 중앙값의 0.5배, 구매 0, 노출 2천 이상 | 신규 생애 |
| L2 전환 없음 | 숙성 지출 > CPA, 구매 0, 결제 시작 0 | 신규 생애 / 기존 최근 7일 |
| L3 손절 | 숙성 지출 > CPA의 1.5배, 구매 0 | 신규 생애 / 기존 최근 7일 |
| L4 고CPA | 지출 > CPA의 2배, 실제 CPA > 목표의 1.5배, 구매 3 이상 | 기존 최근 7일 |
| L5 LPV | 숙성 지출 > CPA의 0.5배, LPV 비용 > 목표의 2배, 구매 0 | 신규 생애 |

신규(cold_start)는 생애 구매 0, 기존(stable)은 생애 구매 1 이상이다.
LPV가 0이면 비용 조건은 무한대로 취급하되 출력에는 무한대 숫자를 쓰지 않는다.
각 레이어의 지출, 노출, 클릭, 구매, LPV 수치는 같은 창이다.
오늘 구매 또는 결제 시작은 최근 창에서 누락될 수 있어 별도 안전 억제 조건으로 사용한다.

계정 현지 시각 12시부터 어제 끝까지, 그 전에는 그제 끝까지 숙성한 것으로 본다.
생애 숙성 지출은 전체에서 오늘과 미숙성 어제를 뺀다. 최근 7일은 미숙성 어제만 뺀다.
구매 수는 숙성 공제하지 않는다. 전체 지출만 문턱을 넘으면 watch(maturing)이다.

48시간 내 수신 픽셀과 광고/계정 구매 합계 대조가 모두 정상이면 valid다.
합계 오차 허용값은 1건과 계정 구매의 2% 중 큰 값이다. 계정 구매 0도 유효할 수 있다.
픽셀 없음은 missing, 합계 또는 구매 별칭 불일치는 contested다.
L1/L2/L3/L5는 valid에서만 끄기 추천을 낸다. 그 밖에는 watch(observation)이다.
L1 기준선 또는 L5 목표가 없으면 해당 레이어는 평가하지 않고 gate 관찰로 알린다.
L0를 사용할 때 두 시각 중 하나라도 없거나 해석할 수 없으면 L0만 평가하지 않고 `l0_start_unknown` 사유를 남긴다. 다른 레이어는 정상 평가한다.

권장 목표는 14일 구매 20건 이상, 구매 있는 날짜 7일 이상일 때만 제안한다.
손익분기 CPA와 14일 총지출/총구매의 1.2배 중 작은 값을 천 원 단위 반올림한다.
반올림 때문에 손익분기보다 높아질 수도 있어 사람이 최종 확정한다.
