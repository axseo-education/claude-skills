# 프레임워크 자동 선택 엔진

Schwartz 인지 레벨 × 매체 × 소구점 → 최적 프레임워크 자동 선택.

## Schwartz 5단계 인지 레벨

출처: Eugene Schwartz, *Breakthrough Advertising* (1966). 타겟이 현재 어디 있는지 진단해야 카피 전략이 결정된다.

| 단계 | 상태 | 판별 기준 | 카피 전략 |
|------|------|-----------|-----------|
| Unaware | 문제 인식 없음 | "내 피부가 원래 이래", "다이어트 생각 없음" | 패턴 인터럽트 + 호기심 후크. HSO/PASTOR/QUEST 적합 |
| Problem Aware | 문제는 알지만 해결책 모름 | "피부가 칙칙한데 뭘 써도 모르겠어", "살을 빼고 싶은데 방법을..." | PAS가 최강. 문제 공감 → 해결 가능성 제시 |
| Solution Aware | 해결책 알지만 제품 모름 | "앰플이 좋다던데 어떤 브랜드가 좋지?", "PT 말고 다른 방법은?" | AIDA/FAB. 해결책 우위 비교 |
| Product Aware | 제품 알지만 미구매 | "메디큐브 알긴 아는데 비싸서", "장바구니에 담아뒀는데" | BAB/FAB. 오퍼 강화, 보증, 사회적 증거 |
| Most Aware | 충성 고객 | 재구매 고객, 브랜드 팔로워 | 4U 헤드라인. 신상품/업셀/로열티 강화 |

### 인지 레벨 판별 실무 기준

- **광고 신규 콜드 트래픽** → 기본값 Unaware/Problem Aware 혼합으로 설정
- **리타겟팅 트래픽** → Product Aware (제품 페이지 방문자)
- **기존 구매 고객 대상 CRM** → Most Aware
- **검색 광고(키워드 광고)** → 키워드 인텐트로 판별. "앰플 추천" = Solution Aware, "메디큐브 앰플 구매" = Product Aware

## 8대 프레임워크

### PAS — Problem → Agitate → Solution

출처: Dan Kennedy, *The Ultimate Sales Letter*. 단문 퍼포먼스 광고의 기본 골격.

**구조 상세:**
- **Problem**: 타겟의 고통을 딱 한 문장으로 찌른다. "거울 보기 싫어졌나요?"
- **Agitate**: 공포가 아닌 공감. "거울 보기 싫어진다" → "메이크업으로 가리는 데도 한계가 있죠. 스스로 피부에 자신 없어진 것, 가족들도 알아채기 시작하고." 고통이 방치될 때 어떻게 확대되는지 그린다.
- **Solution**: 제품명 + 핵심 기능 1개만. 이후 CTA.

**최적 매체**: Meta 피드/GFA/숏폼. 250자 이내 단문에서 가장 강력.
**최적 인지 레벨**: Problem Aware. Unaware에는 문제 공감 앞에 후크 한 줄 추가 필요.
**주의**: Agitate를 협박처럼 쓰면 반감 유발. "이대로면 암 걸린다" → "이대로면 화장도 못 하는 날이 온다" 수준 유지.

---

### AIDA — Attention → Interest → Desire → Action

출처: E. St. Elmo Lewis, 1898. 가장 오래된 프레임워크, 랜딩페이지/장문에서 검증됨.

**구조 상세:**
- **Attention**: 숫자, 질문, 반전 중 하나. "87%의 여성이 세안을 잘못하고 있습니다"
- **Interest**: 왜 이게 중요한지. 통계, 배경, 공감 스토리로 계속 읽게 만든다.
- **Desire**: 제품 사용 후 삶이 어떻게 달라지는지. 감정 + 시각 + 사회적 변화. FAB와 결합.
- **Action**: 단일 CTA. "지금 무료 체험", "오늘만 50% 할인"

**최적 매체**: 랜딩페이지, 뉴스레터, 유튜브 장문 영상 설명.
**최적 인지 레벨**: Solution Aware.

---

### BAB — Before → After → Bridge

출처: 카피라이팅 전통 구조. 테스티모니얼과 영상에서 특히 강력.

**구조 상세:**
- **Before**: 일상 장면. 공감 가는 구체적 상황. "출근 전 거울 앞에서 한숨 쉬던 아침"
- **After**: 감정 + 시각 + 사회적 변화 3가지 동시 제시. "3주 후, 민낯으로 편의점 가는 게 두렵지 않아졌어요. 남편이 먼저 알아봤고, 회사 동료가 시술 받냐고 물었어요."
- **Bridge**: 제품명 + 핵심 기능 1개. "그 변화를 만든 건 메디큐브 엑소좀 앰플 한 병."

**최적 매체**: 영상 스크립트, 카드뉴스, 테스티모니얼 광고.
**최적 인지 레벨**: Product Aware.

---

### PASTOR — Problem → Amplify → Solution → Transformation → Offer → Response

출처: Jeff Walker + John Carlton의 PAS 확장. 장문 세일즈 레터/뉴스레터 전용.

**구조 상세:**
- **Problem**: PAS의 P와 동일
- **Amplify**: 이 문제가 해결되지 않으면 어떤 일이 벌어지는가. 미래 손실 시나리오.
- **Solution**: 제품/서비스 소개
- **Transformation**: 실제 사용자 변화 스토리. 1명의 구체적 케이스.
- **Offer**: 가격, 보너스, 보증, 희소성 묶음.
- **Response**: CTA + 심리적 허들 제거 ("지금 아니면 언제?")

**최적 매체**: 뉴스레터, 긴 랜딩페이지, YouTube 롱폼.
**최적 인지 레벨**: Unaware ~ Problem Aware.

---

### FAB — Feature → Advantage → Benefit

**구조 상세:**
- **Feature**: 제품의 객관적 스펙. "엑소좀 10억 개 함유"
- **Advantage**: 경쟁 대비 우위. "일반 앰플 대비 피부 흡수율 3배"
- **Benefit**: 고객 삶에서 느끼는 변화. "아침 루틴 10분으로 시술 효과"

**최적 매체**: GFA 설명문, 제품 상세페이지 바디카피, 카탈로그.
**최적 인지 레벨**: Product Aware. 단독으로는 약함 — 다른 프레임워크의 Body 파트에 삽입.

---

### HSO — Hook → Story → Offer

출처: Russell Brunson, *DotCom Secrets*. Facebook/IG 광고의 기본 골격.

**구조 상세:**
- **Hook**: 첫 1~2문장. 스크롤 멈춤. PAS 형식이 가장 강력.
- **Story**: 브랜드 창업자 or 실 사용자의 변화 스토리. "처음엔 저도 믿지 않았어요..."
- **Offer**: 제품 + 가격 + CTA. 스토리 감정 여운이 남아 있을 때 제시.

**최적 매체**: Facebook/IG 피드, 영상 광고.
**최적 인지 레벨**: Unaware ~ Problem Aware.

---

### QUEST — Qualify → Understand → Educate → Stimulate → Transition

출처: 콘텐츠 마케팅 프레임워크. 교육 기반 전환.

**구조 상세:**
- **Qualify**: 타겟 독자 지칭. "피부 고민 있는 30-40대 여성분들께"
- **Understand**: 공감 + 문제 정의. 타겟이 공감할 언어로.
- **Educate**: 핵심 인사이트 1-2개. 판단을 바꾸는 정보.
- **Stimulate**: 제품/솔루션이 이 인사이트를 어떻게 해결하는지.
- **Transition**: 자연스러운 CTA. 강요 아닌 초대.

**최적 매체**: 콘텐츠 마케팅, 뉴스레터, 카드뉴스, 유튜브 교육형.
**최적 인지 레벨**: Unaware ~ Solution Aware.

---

### 4U — Urgent + Unique + Ultra-specific + Useful

출처: Michael Masterson (Mark Ford), *Great Leads*. 헤드라인 전용 체크리스트.

**구조 상세:**
- **Urgent**: 지금 읽어야 할 이유. "오늘 밤까지만", "이번 주 안에"
- **Unique**: 다른 곳에서 못 본 각도. "피부과 원장이 직접 쓰는", "대기업이 감추던"
- **Ultra-specific**: 구체적 숫자/조건. "30일", "45,200명", "3주"
- **Useful**: 독자에게 실익. "바로 써먹는", "당장 살에 적용되는"

**최적 매체**: 헤드라인, 이메일 제목, 카드뉴스 1번 슬라이드.
**최적 인지 레벨**: Any. 인지 레벨 무관 헤드라인 체크리스트로 활용.

## 선택 매트릭스

매체그룹 3종:
- **단문 퍼포먼스**: meta_feed / GFA / RSA / 비즈보드 (글자수 제약 있는 퍼포먼스 매체)
- **장문 콘텐츠**: 뉴스레터 / YouTube 설명 / 카드뉴스 바디
- **영상**: 영상 스크립트 / Reels / YouTube In-stream

| 인지 레벨 | 단문 퍼포먼스 | 장문 콘텐츠 | 영상 |
|-----------|-------------|------------|------|
| **Unaware** | 1순위: HSO, 2순위: PAS | 1순위: PASTOR, 2순위: QUEST | 1순위: HSO, 2순위: BAB |
| **Problem Aware** | 1순위: PAS, 2순위: 4U | 1순위: PAS+FAB, 2순위: AIDA | 1순위: PAS, 2순위: BAB |
| **Solution Aware** | 1순위: AIDA, 2순위: FAB | 1순위: AIDA, 2순위: QUEST | 1순위: BAB, 2순위: AIDA |
| **Product Aware** | 1순위: FAB, 2순위: BAB | 1순위: BAB, 2순위: PASTOR | 1순위: BAB, 2순위: FAB |
| **Most Aware** | 1순위: 4U, 2순위: FAB | 1순위: 4U+FAB, 2순위: AIDA | 1순위: 4U, 2순위: BAB |

## 하이브리드 전략

단일 프레임워크만으로 카피를 짜면 구조가 단조로워진다. 장문 매체에서는 하이브리드가 표준.

**기본 하이브리드 규칙:**
- **Hook 파트**: 항상 PAS 또는 HSO. 이 두 개가 후킹 최강.
- **Body 파트**: FAB 또는 QUEST. 정보 전달 + 욕망 형성.
- **Close 파트**: AIDA의 Desire→Action 구조.

**예시 조합 (랜딩페이지):**
```
Hook: PAS (문제→고통 확대→해결 예고) — 3줄
Body: FAB (기능→우위→편익) × 3 세트 — 300자
Social Proof: BAB 형식 후기 1건
Close: AIDA의 Desire→Action (오퍼 + 단일 CTA)
```

**예시 조합 (뉴스레터):**
```
제목: 4U 체크리스트로 검증
도입: HSO (후크→창업 스토리)
본문: QUEST (타겟 지칭→문제 공감→인사이트→솔루션)
클로즈: AIDA Action
```

**단문 매체 하이브리드 불가 원칙:**
GFA 25자, RSA 30자 제약 매체에서는 단일 프레임워크만 사용. 하이브리드 구조 자체가 글자수 초과를 유발. FAB 또는 4U 단일 선택.
